# Transcripts

Raw conversation records. These are useful for revisiting the discussion, but they are not decisions, specs, or current truth.

- [Cairn build session, 2026-11-06 to 2026-11-09](2026-11-06-cairn-build-session.md)

Transcripts are exported from the local opencode session database. They include user and assistant text only. Reasoning, tool calls, and tool output are omitted.

Treat them as exploratory. If a transcript conflicts with an ADR, spec, or research log, the ADR or spec wins. If a transcript contains an idea worth keeping, move it into a research log or an idea document.
