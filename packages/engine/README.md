# @cairn/engine

Pure TypeScript adaptive engine. No filesystem, network, or UI code.

Planned modules:

- Learner model with BKT-lite.
- Mastery and calibration.
- Next-activity policy.
- Help and difficulty policy.
- Review scheduler.
- Decision log and explanations.
- Learner export and import.

See [the engine contract](../../docs/spec/engine-contract-v0.1.md).
