# @cairn/content

Content pack schema, validator, and importers.

Planned work:

- Zod schema for packs, items, rubrics, labs, and policy.
- JSON Schema export for CI and Python.
- Validator with clear errors and warnings.
- Import from Markdown, PDF, DOCX, HTML, EPUB, and a lab repo.
- Pack loader and version migration.

See [the pack schema](../../docs/spec/pack-schema-v0.1.md).
